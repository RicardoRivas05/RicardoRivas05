## 👨‍💻 About Me

I'm a **Computer Science Engineer**, graduated from **Universidad Católica de Honduras (UNICAH)**, with a degree validated by **Universidad Nacional Autónoma de Honduras (UNAH)**.

I'm based in Honduras and focused on **backend engineering**, **REST API development**, and **relational database design**.

I work across the application lifecycle — from understanding business requirements and designing SQL Server databases to developing backend services with **Node.js / LoopBack 4** and building frontend interfaces with **Angular**.

- 🛠️ **What I enjoy:** API design, SQL optimization, system architecture, and solving real business problems.
- 🌱 **Currently exploring:** Scalable backend architectures, cloud technologies, and data engineering.
- 🌍 **Languages:** Spanish (native) · English (learning).
